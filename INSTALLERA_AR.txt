تحديث Tanum InfoScreen – رفع الصور حتى 50 MB

هذا التحديث مخصص حصراً لمشروع tanum-infoscreen.
لا ترفع هذه الملفات إلى مشروع lysekil-buss.

ماذا يتغير؟
- رفع الصور مباشرة من معرض iPhone حتى 50 MB للصورة.
- حفظ الصور في Cloudflare R2، وحفظ بيانات المنشورات في INFO_KV كما هي.
- اختيار صورة لكل منشور، ومعاينتها، وحذفها أو استبدالها.
- حذف صورة R2 القديمة تلقائياً عند استبدالها أو حذف المنشور.
- الإبقاء على رابط التلفاز / ورابط الإدارة / المنشورات الموجودة في INFO_KV.

مهم قبل النشر:
هذا الإصدار يحتاج R2. لا يمكن حفظ صور 50 MB داخل KV. إنشاء R2 قد يكون ضمن الحصة المجانية، لكن Cloudflare قد يفرض رسوماً إذا تجاوز الاستخدام حدود الخطة المجانية. راجع لوحة Cloudflare للاستهلاك والأسعار.

الخطوة 1 – إنشاء مساحة الصور
1. افتح Cloudflare Dashboard.
2. من القائمة اختر R2 Object Storage.
3. اضغط Create bucket.
4. سمِّ الحاوية: tanum-infoscreen-images
5. أنشئ الحاوية. لا تجعلها عامة؛ الكود يعرض الصور عبر Worker.

الخطوة 2 – ربط الحاوية بالـ Worker
1. افتح Workers & Pages ثم tanum-infoscreen.
2. افتح Settings ثم Bindings.
3. اختر Add binding ثم R2 bucket.
4. اكتب Variable name بالضبط: INFO_IMAGES
5. اختر الحاوية: tanum-infoscreen-images
6. احفظ التغييرات.

الخطوة 3 – تحديث الكود
1. في GitHub افتح مستودع ahmadjamalkassab97-dot/tanum-infoscreen.
2. استبدل worker.js بالملف worker.js الموجود في هذه الحزمة.
3. استبدل wrangler.toml بالملف المرفق إذا كنت تستخدمه للنشر عبر Wrangler. لا تحذف ربط INFO_KV الموجود في إعدادات Cloudflare.
4. اعمل Commit changes وانتظر نجاح Deployment في Cloudflare.

الخطوة 4 – الاختبار
1. افتح رابط /admin من iPhone وسجّل الدخول برمز الإدارة الحالي.
2. أنشئ منشوراً تجريبياً وارفع صورة صغيرة أولاً.
3. تأكد من ظهور الصورة في المعاينة وعلى التلفاز.
4. جرّب استبدال الصورة ثم حذفها.
5. بعد نجاح الاختبار، جرّب صورة أكبر. الحد الأقصى في الواجهة والكود 50 MB.

تنبيهات مهمة
- لا تحذف INFO_KV ولا تغيّر اسم ربطه؛ المنشورات الحالية محفوظة فيه.
- لا تغيّر ADMIN_PIN أو رمز الإدارة الحالي.
- هذا الملف لا ينشر التحديث تلقائياً. يجب ربط R2 ثم نشر worker.js وانتظار نجاح Deployment.
- إذا لم تضف INFO_IMAGES binding، سيبقى عرض المنشورات النصية متاحاً، لكن رفع الصور لن يعمل.
- الصور القديمة المخزنة بصيغة Data URL تبقى ضمن بيانات المنشور كما هي. عند استبدالها بصورة جديدة من R2، تُحذف الصورة القديمة من بيانات المنشور.
